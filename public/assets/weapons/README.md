# 火柴人幸存者 · 新武器（回旋镖 / 剑气）

风格对齐 `../obstacles/`：扁平平涂 + 炭黑描边 #2b2b2b，无文字。透明底 RGBA PNG。

## 回旋镖
| 文件 | w×h | 用途 | 锚点 | 碰撞 |
|---|---|---|---|---|
| boomerang.png | 28×20 | 静止图 / UI 图标 / 也可直接当弹体 | setOrigin(0.5,0.5) | 圆形 r≈10，居中 |
| boomerang_01.png | 32×32 | 旋转帧 1（0°） | setOrigin(0.5,0.5)（=重心） | 圆形 r≈11，`body.setCircle(11, 5, 5)` |
| boomerang_02.png | 32×32 | 旋转帧 2（顺时针 120°） | 同上 | 同上 |
| boomerang_03.png | 32×32 | 旋转帧 3（顺时针 240°） | 同上 | 同上 |

主色：木色 #d0a878（降饱和浅橙木）、尖端灰条 #b4aa9c、描边 #2b2b2b。
帧顺序 01→02→03→01 循环，旋转中心已对齐到重心（帧间不抖）。建议 `frameRate: 18~24, repeat: -1`；
3 帧即 120° 一跳，若觉得跳，可只用 boomerang.png + `angle += 720°/s` 代码旋转（更顺，省帧）。

## 剑气斩击波
| 文件 | w×h | 用途 |
|---|---|---|
| slash_01.png | 136×32 | 出刀帧：弧形短（主帧 60% 长） |
| slash.png | 136×32 | 静止主帧（飞行中保持此帧） |
| slash_02.png | 136×32 | 消散帧：拖尾拉长 125%，整体 55% 透明 |

三帧同画布、内容**右对齐**（弧头在右、拖尾向左，飞行方向 = 右）。向其它方向发射时 `setRotation(angle)` 即可。
锚点：`setOrigin(1, 0.5)`（弧头前缘，生成点放在角色前方）；若想按中心定位用 `setOrigin(0.5,0.5)` 也可，三帧同尺寸不会跳。
碰撞：只算弧头，右侧约 40×30：`body.setSize(40, 28).setOffset(94, 2)`。
主色：青白 #cdeef0、内高光 #e6fafa、描边 #2b2b2b。
帧顺序：slash_01（~60ms）→ slash（飞行全程）→ slash_02（命中/到达射程时 ~100ms 后销毁）。不循环。

源图在 `raw/`；`process.py` 复用 `../enemies/process.py` 抠图，旋转帧/扩散帧均由主图程序派生。预览：`raw/preview_x4.png`（灰框=图片边界，红框=32×48 火柴人）。
