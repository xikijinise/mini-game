# 火柴人幸存者 · 场景障碍素材

风格：扁平简笔矢量风，深炭灰粗轮廓 + 低饱和灰绿/灰棕/暖灰平涂，和黑线火柴人、浅米格线背景（#f4f1e8 / #e2dccd）搭配，不抢红围巾主角。
主色：轮廓 #2b2b2b｜松针 #798f79｜阔叶冠 #9faa9c｜灌木 #78886b｜草 #b3bfae｜树干 #8a7a68｜岩石 #a8a39a / #9e998f

全部是透明底 RGBA PNG，已裁到紧包围盒。参考：火柴人 32×48。
碰撞盒 = 相对图片左上角的 (x, y, w, h)；锚点 = setOrigin(0.5, 1)（底部中心）时，偏移 = 碰撞盒左上角相对锚点的 (dx, dy)。

Phaser 用法示例（静态体）：
```js
const t = this.physics.add.staticImage(x, y, 'tree_pine').setOrigin(0.5, 1);
t.body.setSize(8, 16).setOffset(21, 80); // 用左上角那列的 x,y
t.setDepth(y); // 按底边 y 排序，火柴人可走到树冠后面
```
提示：树冠/石头上半部分不参与碰撞，配合按 y 排深度能做出前后遮挡。

源图（GenerateImage 1024 级原图）在 raw/，处理脚本 process.py（近白背景 flood fill→透明、收边 1px、裁紧、按目标高度等比缩放）。预览：raw/preview_x4.png（游戏底色格线上 4 倍放大，红框为 32×48 火柴人）。
